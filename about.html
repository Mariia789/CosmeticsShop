  • Про проєкт

Цей сайт є навчальним проєктом інтернет-магазину косметики, створеним з метою розробки сучасного, стильного та зручного вебресурсу. Основна ідея проєкту — поєднати приємний візуальний дизайн із простою та зрозумілою навігацією, щоб користувачам було комфортно переглядати каталог товарів. На сайті реалізовано каталог косметики з можливістю пошуку, фільтрації за категоріями та ціною, а також додавання товарів у кошик. Проєкт орієнтований на користувачів, які цінують естетику, зручність і логічну структуру сайту. Особливу увагу приділено деталям інтерфейсу та загальному користувацькому досвіду.

Під час створення проєкту були використані базові вебтехнології:

  • HTML — для побудови структури сторінок та розмітки контенту.
  • CSS — для оформлення сайту, створення єдиного стилю, градієнтів, анімацій та адаптивного вигляду.
  • JavaScript — для динамічного відображення товарів, роботи з кошиком, пошуку, фільтрації та обробки подій користувача.
